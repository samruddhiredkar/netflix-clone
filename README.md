# 🍿 Netflix Clone Web Application

A fully responsive, dynamic Netflix streaming web application built with vanilla web technologies and powered by the **TMDB (The Movie Database) REST API**.

## 🚀 Features
* **Dynamic Content Rows:** Automatically fetches and renders categorized movie and TV show lists (Trending Now, Netflix Originals, Action, Comedy, Horror, Romance, Documentaries).
* **Randomized Banner Engine:** Dynamically showcases a featured title with descriptions and high-resolution backdrop art on load.
* **Interactive YouTube Trailers:** Clicking any movie poster instantly fetches and triggers an embedded YouTube trailer modal with seamless close controls.
* **Live Search Filter:** Real-time search functionality that queries the TMDB database dynamically as you type.
* **Responsive Layout & Navigation:** Custom Flexbox grid styling with a scroll-triggered header transition and smooth horizontal scroll navigation tracks.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Vanilla), JavaScript (ES6+ Asynchronous Fetch API)
* **API:** TMDB REST API
* **Version Control & Hosting:** Git, GitHub, GitHub Pages
